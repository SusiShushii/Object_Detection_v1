# Object Detection — เก็บของหน้า Mission Result อัตโนมัติ

บอทรอหน้า **Mission Result** ในเกม หาไอเท็มที่ต้องการในช่อง "Mission Reward" (7×3 ช่อง) จากรูปใน `assets/templates/`
กดเก็บตามจังหวะที่ตั้งไว้ แล้ววนรอบถัดไปเรื่อยๆ ทำงานได้ทั้งจอ 2K (2560×1440) และ 1920×1080 (ปรับสเกลเอง)

**ทุกอย่างรันผ่านไฟล์เดียว: `python main.py`** (พิมพ์เฉยๆ จะขึ้นเมนูให้เลือกเลข)

---

## 1. ติดตั้งครั้งแรก

ดับเบิลคลิก **`install.bat`** (ต้องมี Python 3.14 ถ้าไม่มีจะถามว่าติดตั้งให้ไหม)
สร้างโฟลเดอร์ `.venv` และติดตั้งแพ็กเกจจาก `requirements.txt` ให้อัตโนมัติ (ทำครั้งเดียว)

## 2. เปิด Command Prompt พร้อมใช้งาน

ดับเบิลคลิก **`venv_cmd.bat`** จะได้หน้าต่าง cmd ที่เปิด `.venv` ไว้แล้ว (ในหน้าต่างนี้พิมพ์ย่อได้: `main carrot` = `python main.py carrot`, `crop` = `python main.py crop`)
ถ้าไม่ใช้ cmd นี้: `.venv\Scripts\python.exe main.py ...` หรือ **`run.bat`** (= รัน `main.py` ด้วย `.venv` แล้วค้างหน้าต่างไว้ ใส่ตัวเลือกต่อท้ายได้เหมือนกัน)

---

## 3. คำสั่งทั้งหมด (`main.py`)

```bash
python main.py                          # เมนู: เลือกเลข แล้วใส่ตัวเลือกเพิ่ม (กด Enter ถ้าไม่ใส่)
python main.py help                     # รายการคำสั่งทั้งหมด
python main.py <คำสั่ง> --help          # วิธีใช้ของแต่ละเครื่องมือ
```

| คำสั่ง | ทำอะไร |
|---|---|
| `run` | รันบอทเก็บของ (`python main.py carrot` = `run carrot` พิมพ์ชื่อตรงๆ ได้) |
| `assist` | **คุณคุมเมาส์/เลือกช่องเอง** บอทแค่กดคลิกให้ตรงจังหวะ (ไม่ขยับเมาส์ ไม่ detect) |
| `collect` | เก็บ **ทุกช่อง** ตามเวลา `CLICK_AT_MS` โดยไม่ detect ไอเท็ม (ไม่มี false negative) + บันทึกภาพ loot |
| `prepare` | เตรียมรูปไอเท็มที่ครอปเอง ใส่ `data/inbox/` → ตรวจ + ปรับเป็น 62×65 → `assets/templates/` |
| `crop` | ครอปรูปไอเท็มอัตโนมัติจากภาพที่บอทบันทึก (`output/loot/`) |
| `test` | ทดสอบ detect ไอเท็มบนรูปภาพ (ไม่แตะเมาส์/จอ) |
| `timing` | จับเวลา Mission Reward ขึ้น / ช่องเปลี่ยนสี + วิดีโอ monitor (ไม่คลิก) |
| `analyze` | สรุปสถิติเวลาเปลี่ยนสีจาก `timing.log` แล้วแนะนำค่า `CLICK_AT_MS` |
| `clickat` | ทดสอบกดที่เวลา X ms หลังหัวข้อขึ้น ว่ากดเข้าไหม |
| `fps` | วัดรอบอัปเดตจอ (Hz) และความเร็วจับภาพ |

## 4. รันบอท (`run`)

```bash
python main.py run carrot                # เก็บเฉพาะแครอท (ใส่หลายชื่อได้ ชื่อแรกสำคัญสุด)
python main.py run carrot blue           # เก็บ carrot ก่อน แล้วค่อย blue
python main.py run water_dungeon         # ใช้โปรไฟล์ assets/profiles/Water_Dungeon/priority.txt
python main.py run water_dungeon carrot  # ผสมโปรไฟล์กับชื่อไอเท็มได้ (ลำดับตามที่พิมพ์)
python main.py run                       # เก็บทุกไอเท็มใน assets/templates/ (หรือตาม TARGETS ใน config.py)
python main.py run carrot --dry          # ไม่คลิกจริง แค่ดู log (ใช้ทดสอบก่อนปล่อยจริง)
```

- ใช้งานจริง: เปิดเกมไว้ที่หน้าจอ **ไม่ย่อหน้าต่าง** แล้วรันคำสั่ง บอทจะรอหน้า Mission Result เอง วนไปเรื่อยๆ ไม่มี timeout
- **หยุด:** กด **F12 ค้าง** (เปลี่ยนปุ่มได้ใน `config.py`) หรือ **Ctrl+C**
- ถ้าเกิด error กลางทาง (เช่น จับภาพจอไม่ได้ชั่วคราว) บอทบันทึกลง log แล้วทำงานต่อเอง
- ผลบันทึกที่ **`output/logs/detection.log`** (ภาพประกอบที่ `output/debug/`, `output/loot/`)
- ชื่อไอเท็ม = ชื่อไฟล์ใน `assets/templates/` ไม่ต้องใส่ `.png` ถ้าชื่อไม่ตรงกับไฟล์ จะบอกรายชื่อที่มีให้

**อย่ารัน `run` พร้อมกับ `timing` / `clickat`** เพราะจะแย่งเมาส์และการจับภาพกัน

### โหมดช่วยกด (`assist`) — คุณคุมเมาส์เอง บอทแค่กดให้ตรงจังหวะ

```bash
python main.py assist            # กดต่อเนื่องตาม config จนกว่า Mission Reward จะหายไป (ดูด้านล่าง)
python main.py assist --legacy   # โหมดเดิม: กด MAX_CLICKS_PER_ITEM ครั้งห่างกัน RETRY_AFTER_MS
python main.py assist 3980       # ระบุเวลาเอง (ms หลังเห็นหัวข้อ Mission Reward)
python main.py assist --once     # กดครั้งเดียว (ไม่กดซ้ำ)
python main.py assist --dry      # ไม่คลิกจริง
python main.py assist --record   # บันทึกวิดีโอ + วิเคราะห์ timeline ต่อรอบ (ดูด้านล่าง)
python main.py assist 3988,5000  # กดที่เวลาเหล่านี้เป๊ะๆ ในรอบเดียว (ระบุกี่เวลาก็ได้)
python main.py assist 3988 --second 4990,5000,5010,5020 --record
                                 # ทดสอบเวลาคลิกครั้งที่ 2 (ไอเท็มชิ้นถัดไป): สลับสุ่มทีละรอบ แล้วสรุป "เก็บได้/ทั้งหมด" ของแต่ละเวลา
python main.py assist 3988 --after 1002,1012,1022 --record
                                 # เหมือน --second แต่ระบุเป็น "ms หลังคลิกแรก" (คลิกที่ 2 = 3988 + ค่านั้น)
python main.py assist --first 3992,3996,4000,4004,4008 --record
                                 # ทดสอบเวลาคลิกแรก: สลับสุ่มทีละรอบ แล้วสรุป "เก็บได้/ทั้งหมด" ของแต่ละเวลา (ใช้ร่วมกับ --after ได้)
```

**ค่าเริ่มต้น (ไม่ใส่อะไร) = กดต่อเนื่องตาม `config.py` จนกว่า Mission Reward จะหายไป:**
- ชิ้นที่ 1 กดที่ `CLICK_AT_MS` (3988) แล้วกดกันพลาดอีกครั้งที่ `ASSIST_FIRST_BACKUP_MS` (4000)
- ชิ้นที่ n กดที่ `CLICK_AT_MS + (n-1) × ASSIST_NEXT_AFTER_MS` (1010) แล้วกดกันพลาดอีกครั้งหลัง `ASSIST_BACKUP_AFTER_MS` (10) ms
  เช่น 3988 / 4000 → 4998 / 5008 → 6008 / 6018 → ... ทุก 1010 ms ไปเรื่อยๆ จนหัวข้อหาย (ตรงที่เมาส์อยู่ ไม่ขยับ)
- กดค้าง `CLICK_HOLD_MS` (2)  ถ้าใส่ `--record` จะบันทึกวิดีโอ/trace/timeline **ต่อเนื่องจนกว่าหัวข้อจะหาย** และสรุปว่าแต่ละชิ้น ✓ เก็บได้ / ✗ ไม่เข้า (คลิกหลักกับกันพลาดของชิ้นเดียวกันนับเป็นกลุ่มเดียว)

คุณวางเมาส์บนช่องที่ต้องการเองก่อนหน้า Mission Result ขึ้น บอท**ไม่ขยับเมาส์ ไม่เลือกช่อง ไม่ detect**
พอเห็นหัวข้อ Mission Reward จะนับเวลา แล้วกดคลิกตรงที่เมาส์อยู่ที่เวลาตั้ง (กดค้าง `CLICK_HOLD_MS`)
ถ้า `MAX_CLICKS_PER_ITEM` ≥ 2 จะกดซ้ำอีกครั้งหลัง `RETRY_AFTER_MS` (ค่าใน `config.py`) เป็นการกดตามเวลาเฉยๆ ไม่ได้ตรวจว่าเก็บได้หรือยัง
**`--record`** ต่อรอบจะได้โฟลเดอร์ `output/assist_out/<เวลา>_roundN/`:
- `round.mp4` วิดีโอกรอบรางวัล (ขยาย 2×, 120 fps ความเร็วจริง) แสดงเลขเฟรม / ms / fps กรอบสีทุกช่อง (แดง = ทึบ, เขียว = สีปกติ)
  ช่องที่เมาส์อยู่ = กรอบหนา + ค่า V วงกลมฟ้า = เมาส์ ป้าย `CLICK n` ขึ้นตอนคลิก
- `click1.png`, `click2.png` ภาพเฟรมที่คลิกแต่ละครั้ง  `trace.csv` ค่า V ของช่องใต้เมาส์ทุกเฟรม
- ใน `detection.log` มี timeline สรุป เช่น `ช่องใต้เมาส์ -> พร้อม ... กดครั้งที่ 1 ... -> ทึบ ... -> ว่าง ... กดครั้งที่ 2` และ "ระยะห่างระหว่างคลิก"
ใช้ดูว่าคลิกแต่ละครั้งตกตอนช่องเป็นอะไร (เปิดทำให้ใช้ CPU เพิ่มเล็กน้อย เปิดเฉพาะตอนต้องวิเคราะห์)

ถ้าเมาส์อยู่**นอกกรอบรางวัล** บอทจะไม่คลิก (กันคลิกผิดที่) และยังบันทึกภาพ loot ที่ `output/loot/` เหมือนเดิม

### โหมดเก็บทุกช่อง (`collect`) — ไม่ใช้ detect ไอเท็ม

```bash
python main.py collect          # เก็บทุกช่องที่มีของ ตามเวลา CLICK_AT_MS
python main.py collect --dry    # ไม่คลิกจริง แค่ดู log
```

รอหัวข้อ Mission Reward → รอไอเท็มขึ้นครบ (ดูแค่ "ช่องไม่ว่าง") → วางเมาส์ที่ช่องแรก → ถึง `CLICK_AT_MS` กดช่องแรก
แล้วไล่กดช่องที่เหลือ ซ้าย→ขวา บน→ล่าง → ตรวจซ้ำว่าช่องว่างหมดไหม ช่องไหนไม่ว่างกดอีกรอบ (`COLLECT_MAX_PASSES`)
**เก็บของที่ไม่ต้องการไปด้วย** แต่ไม่พลาดไอเท็มที่ detect ไม่เจอ และยังบันทึกภาพ loot (ทึบ + สีปกติ) ที่ `output/loot/` เหมือนเดิม
(ใช้ `python main.py crop` ตัดรูปไอเท็มใหม่ต่อได้) ตั้ง `COLLECT_GAP_MS` ใน `config.py` เพื่อปรับความเร็วระหว่างช่อง

### โปรไฟล์ (ลำดับความสำคัญต่อด่าน)

สร้างโฟลเดอร์ `assets/profiles/ชื่อด่าน/` ใส่ไฟล์ `priority.txt` บรรทัดละ 1 ไอเท็ม เรียงจากสำคัญที่สุดลงมา
(ดูตัวอย่างที่ `assets/profiles/Example_Dungeon/priority.txt`) แล้วรัน `python main.py run ชื่อด่าน` (ไม่สนตัวพิมพ์เล็ก/ใหญ่)
วางรูป `.png` ไว้ในโฟลเดอร์โปรไฟล์ข้างๆ ได้ ถ้าอยากแยกรูปตามด่าน (ใช้รูปในโฟลเดอร์นั้นก่อน `assets/templates/`)

## 5. ตั้งค่า (`config.py`)

แก้ไฟล์เดียว แล้วรันใหม่

| ค่า | ความหมาย |
|---|---|
| `CLICK_AT_MS` | กดช่องแรกกี่ ms หลังเห็นหัวข้อ Mission Reward โดยไม่รอเห็นสีเปลี่ยน `None` = กดตามสีเปลี่ยนแทน |
| `CLICK_HOLD_MS` | กดค้างกี่ ms ก่อนปล่อยปุ่ม (เกมนับตอนปล่อย ยิ่งสั้นยิ่งเร็ว แต่สั้นกว่าที่คนกดได้จริง) |
| `RETRY_AFTER_MS` | กดแล้วช่องไม่ทึบแว้บ/ไม่ว่างภายในกี่ ms ให้ถือว่าไม่เข้าแล้วกดซ้ำ |
| `MAX_CLICKS_PER_ITEM` | กดช่องเดียวได้สูงสุดกี่ครั้ง |
| `STOP_KEY_NAME` | ปุ่มหยุด `"F1"`–`"F12"`, `"End"`, `"Pause"` |
| `TARGETS` | ไอเท็มเริ่มต้นเมื่อรันโดยไม่ใส่ชื่อ (`None` = ทุกไอเท็ม) |
| `ERROR_RETRY_DELAY` | เกิด error แล้วรอกี่วินาทีก่อนทำงานต่อ |

ค่า `CLICK_AT_MS` / `CLICK_HOLD_MS` วัดมาจากเครื่องและเกมที่ใช้อยู่ ถ้าเปลี่ยนเครื่อง/จอ/ด่าน ให้วัดใหม่ตามหัวข้อ 7

## 6. เพิ่มรูปไอเท็มใหม่

รูปไอเท็มอยู่ใน `assets/templates/ชื่อไอเท็ม.png` ขนาดมาตรฐานคือช่องไอเท็มที่จอ 2K = **62×65 px** (1080p ≈ 46×49)
ชื่อก่อนเครื่องหมาย `-` นับเป็นไอเท็มเดียวกัน เช่น `blue.png` + `blue-dim.png` (ใช้หลายรูปต่อไอเท็มได้)

### วิธี ก. ครอปอัตโนมัติจากภาพที่บอทเก็บไว้ (`crop`)

บอทบันทึกภาพหน้ารางวัลไว้ที่ `output/loot/` ทุกรอบ (ตอนทึบ + ตอนสีปกติ) ใช้ตัดรูปไอเท็มจากภาพเหล่านั้น:

```bash
python main.py crop                    # อ่าน output/loot -> ผลที่ output/crops (new_001.png ... + _sheet.png)
python main.py crop <โฟลเดอร์อื่น>      # อ่านจากโฟลเดอร์อื่น
python main.py crop --min 0.8          # เกณฑ์ "เป็นไอเท็มเดียวกัน" (ค่าเริ่มต้น 0.75)
```

ข้ามช่องว่าง / กล่อง "?" / ป้าย GET! / ไอเท็มที่มีใน `assets/templates/` แล้ว / รูปซ้ำกันเอง
จากนั้นดู `output/crops/_sheet.png` เปลี่ยนชื่อ `new_001.png` เป็นชื่อไอเท็ม (ไม่มีช่องว่าง) แล้วย้ายเข้า `assets/templates/`

### วิธี ข. ครอปเองจากจอ 2K / 1080p ปนกัน (`prepare`)

ใช้เมื่อไอเท็มไม่เคยออกในรางวัลเลย เลยไม่มีใน `output/loot/`:

1. ครอปให้พอดีขอบช่องไอเท็ม (ไม่ต้องรวมตัวเลขจำนวนมุมขวาล่าง) ตอนสีปกติ ไม่มี tooltip/เมาส์ทับ
2. ใส่รูปลง `data/inbox/` ตั้งชื่อไฟล์ = ชื่อไอเท็ม เช่น `data/inbox/blue.png` (ไอเท็มเดียวกันหลายรูป: `blue.png`, `blue-1080.png`)
3. ตรวจก่อน (ยังไม่แตะ `assets/templates/`):

```bash
python main.py prepare             # ตรวจ + รายงาน + ภาพสรุป data/inbox/_report.png
python main.py prepare --src 1080  # บอกว่าทุกรูปครอปจากจอสูง 1080 (1440 = 2K, 2160 = 4K) ไม่ใส่ = เดาจากขนาดรูป
```

4. ถ้าผลโอเค บันทึกเข้า `assets/templates/` (ปรับเป็น 62×65 ให้ และย้ายต้นฉบับไป `data/inbox/done/`):

```bash
python main.py prepare --apply
python main.py prepare --apply --force   # ทับชื่อซ้ำ / บันทึกแม้ถูกเตือน (ซ้ำ, ช่องว่าง, เบลอ, สัดส่วนผิด)
```

ตัวเครื่องมือเตือน/ข้าม: เล็กเกินไป, เบลอ, ช่องว่าง/เรียบ, สัดส่วนผิดช่อง, มีพื้นโปร่งใส, ซ้ำกับไอเท็มเดิม

### ตรวจว่า detect ได้จริง (`test`)

ไม่ใช้เมาส์ ไม่จับหน้าจอ ใช้กับรูปภาพอย่างเดียว:

```bash
python main.py test output\loot\20261008_202107_2_normal.png blue   # รูปกรอบรางวัลที่บอทเก็บ หรือภาพแคปจอเต็ม 16:9
python main.py test img1.png img2.png water_dungeon                 # หลายรูป / ชื่อโปรไฟล์ได้
python main.py test img.png                                         # ไม่ใส่ชื่อ = ทุกไอเท็ม
```

ผลเป็นตาราง เจอ/ไม่เจอ คะแนน (ผ่านเมื่อ ≥ 0.75) ช่อง สถานะ และภาพวาดกรอบที่ `output/test_out/<ชื่อรูป>_boxes.png`
(กรอบเขียว = ผ่านเกณฑ์, เหลือง = เจอแต่ไม่ใช่ช่องแรก, แดง = เกือบเจอแต่ต่ำกว่าเกณฑ์)

## 7. วัดจังหวะ (ไว้ตั้งค่า `CLICK_AT_MS`)

ทั้งหมดนี้รันบนเครื่องที่เปิดเกม ปิดบอทก่อน และ **ไม่ย่อหน้าต่างเกม**

### `timing` — จับเวลาโดยไม่คลิก

```bash
python main.py timing                          # หน้าต่าง monitor สด + บันทึกวิดีโอทุกรอบ + log (หยุด: F12)
python main.py timing --no-window              # ไม่เปิดหน้าต่าง monitor
python main.py timing --no-video               # ไม่บันทึกวิดีโอ
python main.py timing --no-window --no-video   # เบาที่สุด เหมาะตอนเก็บสถิติหลายรอบ
```

เปิดทิ้งไว้ **ก่อน** หน้า Mission Result จะขึ้น ปล่อยให้ผลรางวัลทยอยขึ้นเอง (ไม่ต้องคลิก/แตะเมาส์)
จะ log ว่าหน้า Mission Reward ขึ้นกี่ ms (นับเป็น 0), แต่ละช่องขึ้นตอนไหน, เปลี่ยนจากทึบเป็นสีปกติตอนกี่ ms และเฟรมเรตจริง
กรอบในหน้าต่าง/วิดีโอ: **แดง** = ทึบ, **เขียว** = สีปกติ, **เหลือง** = เพิ่งเปลี่ยนเป็นสีปกติ
ผลที่ `output/logs/timing.log` และ `output/timing_out/<เวลา>_roundN/` (วิดีโอ `.mp4` + รูปตอนขึ้น/ตอนเปลี่ยนสี)

ทดสอบระบบโดยไม่เปิดเกมได้ด้วยรูป: `python main.py timing --image <รูป>` หรือ `python main.py timing --selftest dim.png normal.png`

### `analyze` — สรุปสถิติจาก `timing.log`

```bash
python main.py analyze                      # อ่าน output/logs/timing.log
python main.py analyze path\to\timing.log
```

เก็บอย่างน้อย **10 รอบ** ด้วย `timing` แล้วรัน จะได้ตารางต่อรอบ ค่าต่ำสุด/เฉลี่ย/สูงสุด/SD ของเวลาที่ช่องเปลี่ยนเป็นสีปกติ และคำแนะนำค่าที่ควรตั้ง

### `clickat` — ทดสอบกดที่เวลา X ms ว่าเข้าไหม

```bash
python main.py clickat 3988 --slot 1                 # กดช่องที่ 1 ที่ 3988 ms หลังหัวข้อขึ้น (วนทุกรอบ จนกด F12)
python main.py clickat 3988 blue                     # กดช่องของไอเท็ม blue (ชื่อ/โปรไฟล์เหมือน run)
python main.py clickat 3985,3988,3992 --slot 1       # หลายเวลา: สลับสุ่มทีละรอบ แล้วสรุป "เข้า/ทั้งหมด" ของแต่ละเวลา
python main.py clickat 4000 --hold 2,5,10 --slot 1   # ทดสอบเวลากดค้าง (ms) หลายค่า สลับทีละรอบ
python main.py clickat 3988 --dry                    # ไม่คลิกจริง ดูเวลาและการเลือกช่องเฉยๆ
```

- `--slot 1` = ช่องที่ 1 (ซ้ายบน) เลข 1–21 นับซ้าย→ขวา บน→ล่าง หรือใช้ `--slot 1,3` (แถว 1 คอลัมน์ 3)
- แต่ละรอบกด 1 ช่อง แล้ว log `ผล: กดเข้า ✓` หรือ `ไม่เข้า ✗` พร้อมสรุปสะสม เช่น `3988ms/ค้าง2=15/15`
- **จะเก็บไอเท็มช่องนั้นจริงทุกรอบ**

### `fps` — วัดรอบอัปเดตจอและความเร็วจับภาพ

```bash
python main.py fps
```

บอกโหมดจอ (ความละเอียด/Hz), DWM รวมภาพกี่ครั้งต่อวินาที, `mss` จับภาพได้กี่ครั้งต่อวินาที (เขียนที่ `output/logs/fps_probe.txt`)
ต้องรันในหน้าจอของ session ที่เปิดเกมอยู่ (รันผ่าน SSH ไม่ได้ เพราะจับหน้าจอไม่ได้)

### ขั้นตอนตั้งค่าเวลาใหม่ (เมื่อเปลี่ยนเครื่อง/จอ/เกม)

1. `python main.py timing --no-window --no-video` เก็บ 10+ รอบ แล้วกด F12
2. `python main.py analyze` ดูเวลาที่ช่องเปลี่ยนเป็นสีปกติ
3. ตั้ง `CLICK_AT_MS` ใน `config.py` ให้ใกล้ค่าต่ำสุดที่เห็น (เผื่อไว้เล็กน้อย)
4. ยืนยันด้วย `python main.py clickat <เวลา> --hold <ms> --slot 1` สัก ~30 รอบ ให้ได้อัตราเข้า ≥ ~97% (กดพลาดครั้งเดียวเสียเวลาไปมากกว่าที่ได้จากการกดเร็ว)
5. ถ้าไม่ผ่าน ตั้ง `CLICK_AT_MS = None` ให้บอทกดตามสีเปลี่ยนแทน (ช้ากว่าราว 20 ms แต่ไม่ต้องรู้เวลา)

```
main.py            จุดเริ่มต้นเดียว (เมนู + คำสั่ง)
config.py          ตั้งค่าหลัก
install.bat  run.bat  venv_cmd.bat
src/detector/      โค้ดหลักของบอท (ไม่ต้องรันเอง)
    app.py           ลูปหลักของบอท (run)
    clicker.py       จังหวะกด/คลิก/ขยับเมาส์
    detection.py     หาไอเท็มด้วย template matching
    screen.py        จับภาพหน้าจอ
    profiles.py      อ่านโปรไฟล์ priority.txt
    paths.py         ที่อยู่ไฟล์/โฟลเดอร์ทั้งหมด (แก้ที่เดียว)
tools/             เครื่องมือ (เรียกผ่าน main.py): prepare, crop, test, timing, analyze, clickat, fps
assets/            ข้อมูลที่โปรแกรมใช้
    templates/       รูปไอเท็มที่ต้องการเก็บ
    markers/         รูปอ้างอิง: หัวข้อ Mission Reward, ป้าย GET!, ช่องว่าง, กล่อง "?"
    profiles/        ลำดับความสำคัญต่อด่าน (priority.txt)
data/inbox/        ที่ใส่รูปครอปเองให้ prepare
output/            สิ่งที่โปรแกรมสร้าง (ลบทิ้งได้ ไม่ขึ้น git)
    logs/            detection.log, timing.log, fps_probe.txt
    debug/ loot/ crops/ test_out/ timing_out/
```

ที่อยู่ทั้งหมดอ้างอิงจากตำแหน่งของโปรเจกต์ (ไม่ใช่โฟลเดอร์ที่สั่งรัน) จึงย้ายโฟลเดอร์ไปไว้ที่ไหน หรือรันจากโฟลเดอร์ไหนก็ใช้ได้

## 9. ปัญหาที่พบบ่อย

- **ไม่คลิกเลย:** บอทกดเฉพาะตอนเห็นหัวข้อ "Mission Reward" ในหน้าจอ ตรวจ log ว่ามี `[loot] เห็น Mission Reward` ไหม ถ้าไม่มี แปลว่าจับภาพไม่ตรงตำแหน่ง/เกมถูกย่อ/จอไม่ตรงสเกล
- **เจอแต่ไม่กด / กดไม่เข้า:** ดูบรรทัด `ตั้งเวลา ... click #1` ตามด้วย `เก็บได้แล้ว` ถ้าเห็น `คลิกไม่เข้า -> กลับไปกดใหม่` บ่อย ให้ลองตั้ง `CLICK_AT_MS = None` หรือวัดเวลาใหม่ (หัวข้อ 7)
- **ไอเท็มไม่ถูก detect:** ลอง `python main.py test <ภาพ> <ชื่อ>` ดูคะแนน (ต้อง ≥ 0.75) tooltip หรือเมาส์ที่ทับไอเท็มทำให้คะแนนตก ควรขยับเมาส์ออกนอกกรอบรางวัล
- **เก็บผิดตัวที่สีคล้ายกัน:** บอทตรวจทิศทางสีแล้ว ถ้ายังพลาด ส่ง log และภาพใน `output/debug/` (กรอบ `*_found_boxes.png`) มาดูได้
- **`BitBlt Access denied` / จับภาพไม่ได้:** เกิดเมื่อหน้าต่างถูกย่อ หน้าจอล็อก หรือ session ตัดการเชื่อมต่อ บอทจะรอแล้วลองใหม่เอง แต่ต้องปลดล็อก/เปิดเกมกลับมา
- **คำสั่งไม่รู้จัก `python`:** รันผ่าน `venv_cmd.bat` หรือ `.venv\Scripts\python.exe` (ไม่ใช้ Python ของ Microsoft Store)
